# 🥗 Health Food — Персональные меню питания

Проект для генерации еженедельных меню для Сергея и Эльвиры с учётом медицинских показаний, рекомендаций тренера и доступной техники.

## Структура проекта

```
health_food/
├── profiles/          # 🔒 Биоданные (в .gitignore, не пушатся)
│   ├── sergey.json    # Вес, рост, цель Сергея — обновлять при взвешивании
│   └── elvira.json    # Вес, рост, цель Эльвиры
│
├── rules/             # Правила питания (Markdown)
│   ├── sergey_diet.md # Ограничения диетолога — СТРОГО
│   └── elvira_diet.md # Рекомендации тренера
│
├── equipment/
│   └── equipment.md   # Техника и посуда, методы готовки
│
├── menus/
│   └── 2026/          # HTML-меню по неделям
│       └── week_YYYY-MM-DD_пн-вс.html
│
├── history/
│   └── menu_history.db  # SQLite: меню, оценки блюд, история веса
│
├── docs/              # 🔒 Исходники от врачей/тренеров (в .gitignore)
│
├── .claude/skills/
│   └── make-menu.md   # Скилл для генерации нового меню
│
└── index.html         # GitHub Pages — список всех меню
```

## Как пользоваться

### Сгенерировать меню на неделю
```
/make-menu
```
Claude прочитает профили, правила, историю блюд — и создаст HTML-меню + запушит на GitHub Pages.

### Обновить вес
```
обнови вес Сергея — 127 кг
```

### Отметить что не понравилось
```
нам не понравилась треска
```
Блюдо помечается как нежеланное и больше не предлагается.

### Отметить что понравилось
```
нам понравилась овсянка с яблоком, хотим снова
```

### Посмотреть динамику веса
```
покажи динамику веса
```

## База данных (SQLite)

`history/menu_history.db` содержит три таблицы:

| Таблица | Назначение |
|---|---|
| `menu_weeks` | Каждая неделя меню с датами и калориями |
| `menu_dishes` | Блюда с полем `liked` (NULL/1/0) |
| `weight_history` | Динамика веса по датам |
