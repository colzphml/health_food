## ШАГ 2 — Рассчитываем калорийность

### Сергей (динамический расчёт по текущему весу)
```
Возраст = текущий год - 1991
BMR     = 10 × вес_кг + 6.25 × 183 - 5 × возраст + 5
TDEE    = BMR × 1.375   (умеренная активность)
Цель    = TDEE - 500    (дефицит для похудения)
Минимум = 1800 ккал (не опускать ниже)
```

Вычисли и запиши итоговую цифру.

### Эльвира
Фиксировано: **1700 ккал** / Б 100г / Ж 65г / У 180г

## ШАГ 3 — Составляем меню на 7 дней (Пн–Вс)

### Структура дня Сергея (5 приёмов):
| Приём | % калорий | Примерный состав |
|---|---|---|
| Завтрак | 25% | Каша (гречка/овсянка/булгур) или яйца/омлет + фрукт |
| Перекус | 10% | Кисломолочное + фрукт |
| Обед | 30% | Суп + гарнир (80–150 г) + белок (≤120 г) |
| Полдник | 10% | Творог / кефир / йогурт + фрукт / хлебцы |
| Ужин | 25% | Белок (≤120 г) + тушёные овощи (200+ г) + гарнир (80–150 г) |

### Структура дня Эльвиры:
- Любое количество приёмов в рамках 1700 ккал
- В тренировочный день: +приём пищи до и после тренировки
- Свежие овощи обязательно ≥500 г/день
- Структура порции: белок 150 г + углеводы 150–200 г + овощи 200 г

### Правила разнообразия:
- **Белок** чередовать по дням: курица → индейка → рыба → творог → яйца → говядина → кролик
- **Крупы** чередовать: гречка → овсянка → перловка → булгур → бурый рис → киноа → пшено
- **Овощи** — каждый день разные, сочетание тушёных + свежих
- Одно блюдо — не чаще 1 раза в неделю
- Блюда из истории «не понравилось» (liked=0) — **НИКОГДА не предлагать**
- Блюда последних 4 недель — максимально избегать повторений

### Обязательная проверка для Сергея:
Проверь каждый день по чеклисту:
- [ ] Нет сахара, белого хлеба, белого риса, жареного в масле
- [ ] Нет острых специй, маринадов, копчёностей, майонеза
- [ ] Нет винограда, изюма, фиников, кислых ягод, грейпфрута, лимона
- [ ] Нет алкоголя, газировки, пакетированных соков
- [ ] Разовая порция белка ≤ 120 г
- [ ] Гарнир 80–150 г (варёный вес)
- [ ] Молоко ≤150 мл в день, кефир ≤200 мл, сметана ≤15 г, сыр ≤50 г, творог ≤120 г
- [ ] Суммарно овощей ≥400 г/день
- [ ] Итог ккал в норме ±50 ккал

## ШАГ 4 — План готовки

Определи **2 дня batch-cooking** (обычно воскресенье + среда) и распиши:

**Batch-cooking воскресенье (на Пн–Ср):**
- Turbo Cuisine: суп / рагу (25–30 мин под давлением)
- Кастрюля: крупа 1 (гречка или перловка, выход ~900 г)
- Кастрюля: крупа 2 (если нужна)
- Куриная грудка: варить вместе с супом или отдельно

**Batch-cooking среда (на Чт–Пт):**
- Обновление супа (борщ / другой вид)
- Свежая крупа
- Рыба или котлеты (гриль / духовка)

**Свежее каждый день:**
- Омлеты, яичница (сковорода, минимум масла)
- Свежие салаты
- Гриль-блюда (Optigrill — мясо/рыба без масла)

Пиши пошаговые инструкции как в примере (step-num + step-text + tip-box).

## ШАГ 6 — Создаём HTML-файл

**Имя:** `menus/2026/week_YYYY-MM-DD_пн-вс.html`
(YYYY-MM-DD = понедельник недели)

**Требования:**
- Полностью копируй CSS-переменные и стили из `menus/2026/week_2026-04-22_vt-ch.html`
- Перед `<header>` — кнопка возврата: `<a class="back-link" href="../../index.html">← Все меню</a>`
- Та же структура: back-link → header → nav (📅 Дни / 🛒 Покупки / 🍳 Готовка) → sections
- Секция «Дни»: 7 колонок (grid 3+4 или 4+3, с `@media` для мобилки)
- Карточки с flip-modal (onclick → openCard → #card-modal)
- Секция «Покупки»: сгруппированный список
- Секция «Готовка»: cook-block с пошаговыми шагами, tip-box, storage-grid
- В `<title>` и `<h1>` — период недели
- Если меню разное для Сергея и Эльвиры — добавь второй nav-tab «👤 Эльвира»

Пример структуры карточки (скопируй из эталона, не изобретай новый дизайн).

## ШАГ 7 — Запись в БД

```bash
# Вставляем новую неделю
sqlite3 history/menu_history.db "
INSERT INTO menu_weeks (week_start, week_end, days_label, filename, kcal_sergey, kcal_elvira)
VALUES ('YYYY-MM-DD', 'YYYY-MM-DD', 'Пн–Вс', 'menus/2026/week_YYYY-MM-DD_пн-вс.html', KCAL_S, 1700);
"

# Получаем id новой недели
WEEK_ID=$(sqlite3 history/menu_history.db "SELECT last_insert_rowid();")

# Вставляем каждое блюдо (повторить для всех 35 блюд)
sqlite3 history/menu_history.db "
INSERT INTO menu_dishes (week_id, day_name, meal_type, dish_name, kcal)
VALUES ($WEEK_ID, 'Понедельник', 'завтрак', 'НАЗВАНИЕ', KCAL);
"
```

**Важно:** поле `liked` оставляем NULL — пользователь заполнит после.

## ДОПОЛНИТЕЛЬНЫЕ КОМАНДЫ (без make-menu)

Пользователь может сказать:

**«Обновить вес Сергея — 127 кг»:**
```bash
sqlite3 history/menu_history.db "
INSERT INTO weight_history (person, weight_kg, notes)
VALUES ('Сергей', 127.0, 'обновление');
"
```
И обнови `profiles/sergey.json` → поле `weight_kg`.

**«Это нам не понравилось — [блюдо]»:**
```bash
sqlite3 history/menu_history.db "
UPDATE menu_dishes SET liked = 0
WHERE dish_name LIKE '%НАЗВАНИЕ%';
"
```
Подтверди: «Блюдо "[название]" помечено как нежеланное — больше не буду предлагать».

**«Это нам понравилось — [блюдо]»:**
```bash
sqlite3 history/menu_history.db "
UPDATE menu_dishes SET liked = 1
WHERE dish_name LIKE '%НАЗВАНИЕ%';
"
```

**«Покажи динамику веса»:**
```bash
sqlite3 history/menu_history.db "
SELECT person, weight_kg, recorded_at
FROM weight_history
ORDER BY person, recorded_at;
"
```
Выведи в виде таблицы с изменениями (дельта от предыдущего взвешивания).
